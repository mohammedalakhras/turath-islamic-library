# خزانة الآثار 🏛️

مكتبة رقمية مجانية للكتب الأثرية والتراثية — صفحات ثابتة 100% (بلا أي Build) لضمان أرشفة كاملة وسريعة في محركات البحث، مستضافة على GitHub Pages.

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub وارفع محتوى هذا المجلد (شاملاً ملف `.nojekyll` المخفي).
2. استبدل `USERNAME/REPO` في: `data/manifest.json` (حقل siteUrl) + `robots.txt` + `sitemap.xml` + ملفات كتاب النموذج.
   (أو أعد توليد المشروع بالأمر: `python build_khizana.py USERNAME REPO`)
3. المستودع ← Settings ← Pages ← Deploy from a branch ← `main` ← `/(root)`.
4. في Google Search Console: أضف الموقع وأرسل `sitemap.xml`.

## إضافة كتاب جديد (الديناميكية)

افتح ملف `PROMPT-ARGON.txt` وأرسله مع ملفات المستودع + نص الكتاب إلى Argon،
ثم انسخ مخرجاته إلى المستودع وارفعها — لا يحتاج الأمر أي تعديل على ملفات المنصة نفسها.

## الميزات

- نص كل قسم في HTML ثابت → SEO كامل + JSON-LD (Book/Chapter/Breadcrumb).
- ٣ أوضاع قراءة (نهاري/ورقي/ليلي)، ٣ خطوط عربية، حجم خط وتباعد قابلان للضبط.
- حفظ موضع القراءة تلقائياً (LocalStorage) واستئنافه في أي جهاز/متصفح.
- مشجرات توضيحية تفاعلية لكل كتاب وكل قسم (مع تنبيه أنها ليست من تأليف الكاتب).
- زر تحميل PDF (أو طباعة تلقائياً عند غياب الملف).
