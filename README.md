# خزانة الأثر 🏛️

مكتبة رقمية مجانية للكتب الأثرية والتراثية — صفحات ثابتة 100% لأرشفة كاملة على GitHub Pages، بتجربة قراءة فاخرة.

## النشر
1. أنشئ مستودعاً وارفع محتوى المجلد (شاملاً `.nojekyll`).
2. استبدل `USERNAME/REPO` في: `data/manifest.json` + `robots.txt` + `sitemap.xml` + ملفات كتاب النموذج — أو ولّد بالأمر: `python build_khizana.py USERNAME REPO`.
3. Settings ← Pages ← Deploy from branch ← main ← /(root).
4. أرسل `sitemap.xml` في Google Search Console.

## إضافة كتاب جديد
أرسل `PROMPT-ARGON.txt` + ملفات المستودع + نص الكتاب إلى Argon، ثم انسخ مخرجاته وارفعها. البرومبت الجديد يولّد: خرائط أفكار متعددة المستويات للمشجرات، الحواشي والمصادر، الترميز البلاغي (آيات/أحاديث/أقوال/شعر)، وبطاقة الكتاب.

## الغلاف الحقيقي (اختياري)
ضع صورة أول صفحة من الـ PDF باسم `cover.jpg` داخل مجلد الكتاب، واضبط الحقل `"cover": "cover.jpg"` في `data/manifest.json` — تظهر تلقائياً في بطاقة الكتاب بالرئيسية.

## الميزات
- نص كل قسم في HTML ثابت → SEO كامل + JSON-LD.
- ٣ أوضاع قراءة، ٣ خطوط عربية، حجم/تباعد قابلان للضبط.
- حفظ موضع القراءة تلقائياً + إشارات مرجعية على كل فقرة + صفحة «إشارتي».
- مشجرات أفكار هرمية للمذاكرة (٣–٥ مستويات) مع تنبيه أنها ليست من تأليف الكاتب.
- الحواشي والمصادر في نهاية كل صفحة بروابط ذهاب/عودة.
- بحث محلي يتجاهل التشكيل والهمزات.
- زر تحميل PDF (أو طباعة تلقائية عند غيابه).
