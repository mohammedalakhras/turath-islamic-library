# المكتبة الإلكترونية للكتب الأثرية والتراثية (GitHub Pages)

مشروع منصة قراءة وأرشفة كتاب **«مُذكِّرةٌ في الاحتِجَاجِ لأُصُولِ الإِسْلَامِ»** لتأليف **عبد القادر بن محمد أنيس البكّور**، مُصمّم خصيصاً لتصدّر نتائج محركات البحث (SEO) والعمل مجاناً عبر **GitHub Pages (`github.io`)**.

## هيكل المشروع
- `index.html`: الصفحة الرئيسية الثابتة (Static HTML) متضمنةً البيانات المهيكلة `Schema.org/Book` والمشجرات التوضيحية التفاعلية ونص الكتاب.
- `css/style.css`: تنسيقات الهوية التراثية المتجاوبة (الوضع النهاري، الليلي، وورق البردي).
- `js/app.js`: ميزات حفظ مكان الوصول عبر `localStorage`، البحث الفوري، وطيّ القوائم (`Off-canvas`).
- `assets/`: يحتوي على النسخة الأصلية من الكتاب بصيغة PDF.
- `sitemap.xml` و `robots.txt` و `.nojekyll`: ملفات الأرشفة الفورية في Google Search Console.
