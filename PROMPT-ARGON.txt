# المهمة: تحويل كتاب إلى حزمة صفحات ثابتة لمنصة «خزانة الأثر» (برومبت v2)

## السياق
مرفق معك:
1) ملفات منصة «خزانة الأثر» (مستودع GitHub Pages ثابت بلا أي build).
2) النص الكامل للكتاب المطلوب تحويله.
مهمتك: توليد ملفات هذا الكتاب فقط ودمجها في المنصة بحيث تنشر مباشرة.

## المرجع الذهبي — التزم به حرفياً
ادرس كتاب النموذج: books/al-arbaeen-nawawiyya/ (index.html و pages/001.html و pages/002.html و search-index.json).
كل ملف تولده يطابق بنية النموذج (الترويسة، الترتيب، الكلاسات). استبدل المحتوى المحدد بين تعليقات ARGON فقط.
محظور تعديل ملفات المنصة: assets/ و index.html و search.html و bookmarks.html و about.html و 404.html.

## القواعد المقدسة
1) المتن حرفي 100%: لا حذف، لا إضافة، لا تلخيص، لا تصحيح، لا إعادة ترتيب.
2) **لا تسقط أي حاشية أو تخريج أو مصدر ورد في الكتاب** — لها نظام خاص أدناه.
3) لا كلام من عندك داخل المتن. الاستثناء الوحيد: عقد المشجرات ورسوماتها (لأنها واجهة توضيحية تصرح بأنها ليست من تأليف الكاتب).
4) عند التحويل: & → &amp; ، < → &lt; ، > → &gt;
5) ﷺ وكل الرموز كما هي (UTF-8).

## الترميز البلاغي (إلزامي — لتمييز المحتوى بصرياً)
- الآيات داخل السرد: <span class="aya">﴿…﴾</span> — والآية المستقلة بفقرة كاملة: <p class="aya-block">﴿…﴾</p>
- الحديث داخل السرد: <span class="hadith">«…»</span> — والحديث المستقل: <div class="hadith-block">…</div>
- أقوال أهل العلم والنقول المنقولة: <blockquote class="quote"><p>نص القول حرفياً</p><cite>— اسم القائل إن ذكره الكتاب فقط</cite></blockquote>
- الشعر: كل بيت في <p class="poetry"><span>الصدر</span><span>العجز</span></p>
- عناوين h2/h3 من عناوين الكتاب الأصلية فقط (إن لم توجد فلا تخترع داخل المتن).
- <strong> فقط لما هو مؤكد في الأصل.

## الحواشي والمصادر (إلزامي)
1) انقل كل حواشي الكتاب الأصلية (تخريجات، مصادر، شروح الحاشية) إلى نهاية الصفحة:
<section class="sources" id="sources">
  <h2 class="sources__t">الحواشي والمصادر</h2>
  <ol>
    <li id="fn-1">نص الحاشية الأصلي حرفياً. <a class="back" href="#ref-1" aria-label="العودة إلى المتن">↩</a></li>
  </ol>
</section>
2) في المتن، عند موضع الحاشية الأصلي: <sup class="fn" id="ref-1"><a href="#fn-1">١</a></sup> (رقّم بالأرقام العربية ١،٢،٣…)
3) لا تخترع مصادر ولا تحذفها ولا تدمجها. إن خلا القسم من الحواشي احذف القسم كله.

## المشجرة = خريطة أفكار للمذاكرة (أهم تغيير في v2)
الغرض: أن يفتح الطالب المشجرة فيحيط بالقسم كله ويذاكره. ليست فهرساً ولا نسخاً للعناوين.
1) من ٣ إلى ٥ مستويات: الجذر = القسم، ثم المحاور الرئيسية، ثم النقاط، ثم التفاصيل/الأمثلة/الاستثناءات.
2) كل عقدة = فكرة مصاغة بأسلوبك في ٢–٨ كلمات. **ممنوع منعاً باتاً نسخ جملة من المتن أو أول الفقرة أو العنوان الطويل كما هو.**
3) كل أب من ٢ إلى ٧ أبناء. العقدة تُغذي المذاكرة: قاعدة/شرط/مثال/استثناء/دليل/تقسيم.
4) إن تجاوزت العقد ٢٠: اضبط "collapsed": true للمستوى الثالث فما دون.
5) مثال نموذجي (حديث النيات):
{ "label": "الحديث الأول: الأعمال بالنيات", "cls": "t-root", "children": [
  { "label": "الراوي: عمر بن الخطاب" },
  { "label": "القاعدة: صحة العمل بالنية", "children": [
    { "label": "النية ميزان القبول" }, { "label": "لكل امرئ ما نوى" } ] },
  { "label": "مثال تطبيقي: الهجرة", "children": [
    { "label": "هجرة لله ورسوله", "collapsed": true, "children": [ { "label": "ثوابها: مقبولة" } ] },
    { "label": "هجرة لدنيا أو زواج" } ] } ] }
6) مشجرة الغلاف: الكتاب (t-root) → الأبواب (t-chapter + href) → أهم ٢–٤ محاور لكل باب (collapsed: true).
7) أبقِ figcaption التنبيه بنصه الحرفي في كل مشجرة:
«تنبيه: هذه المشجرة ليست من تأليف الكاتب، وإنما هي رسم توضيحي لتسهيل القراءة والتصفح فقط.»

## رسومات توضيحية داخل المتن (اختياري بحكمة)
إن أفاد فهمَ مقطع (تقسيم، علاقة، مقارنة): أدرج مشجرة مصغرة بعد الفقرة ذات الصلة (بحد أقصى ٢ لكل قسم):
<figure class="tree-figure tree-figure--inline"> … نفس بنية المشجرة والتنبيه … <div class="tree" id="tree-figN"></div><script type="application/json" data-tree="tree-figN">…</script></figure>
لا تقسم المتن بسببها ولا تحذف شيئاً منه.

## صفحة القسم (pages/NNN.html) — ما تستبدله
- وسم <html> أضف: data-book-title="{الكتاب}" data-book-author="{المؤلف}".
- <title>: «{عنوان القسم} — {اسم الكتاب} | خزانة الأثر». meta description: أول 140–160 حرفاً من المتن حرفياً.
- canonical/og:url من siteUrl في manifest. link rel=prev/next (الأول prev=../index.html، الأخير بلا next).
- JSON-LD (Chapter + BreadcrumbList) محدّث.
- بطاقة الكتاب تحت عنوان الفصل (كما في النموذج):
<div class="book-strip"><span>من كتاب: <b>{الكتاب}</b></span><span>تأليف: <b>{المؤلف}</b></span><span class="book-strip__chip" id="read-time" hidden></span></div>
- على وسم <article> أضف: data-words="{عدد كلمات متن القسم}" (تحسبه المنصة لزمن القراءة).
- nav#toc-nav: فهرس هرمي بعناوين حقيقية (الأبواب + أقسامها الفرعية) مع is-here وaria-current للقسم الحالي.
- زر PDF: إن وُجد الملف: data-pdf="{slug}.pdf" و href="../{slug}.pdf"، وإلا data-pdf="".
- pager: السابق/التالي بعناوينها الحقيقية، والأخير زر «العودة إلى فهرس الكتاب».

## صفحة الغلاف (books/{slug}/index.html)
- title: «{الكتاب} — {المؤلف} | خزانة الأثر» + JSON-LD نوع Book.
- book-desc: سطران وصفيان (الموضع الوحيد المسموح فيه الكتابة الوصفية).
- المشجرة الكبرى (كما فوق) + فهرس كامل + زر «ابدأ القراءة» → pages/001.html.
- إن وُجد ملف صورة غلاف (cover.jpg) في مجلد الكتاب فاذكره في manifest فقط؛ المنصة تعرضه تلقائياً.

## ملفات إضافية
1) books/{slug}/search-index.json: {"book":"{slug}","title":"…","entries":[{"u":"pages/001.html","t":"{عنوان القسم}","x":"{كل متن القسم نصاً مجرداً بلا HTML، شاملاً الحواشي}"}]}
2) حدّث data/manifest.json: أضف سجل الكتاب (slug, title, author, description, pageCount, pdf أو "", cover أو "", tags حتى 4, added اليوم) دون مس الكتب الأخرى.
3) حدّث sitemap.xml: أضف الغلاف وكل صفحات الأقسام مع lastmod اليوم. النطاق = siteUrl.

## قواعد التسمية
- slug لاتيني صغير بشرطات من اسم الكتاب (كتاب التوحيد → kitab-at-tawhid).

## التحقق الذاتي الإلزامي (أرفق الجدول)
- عدد الأقسام = عدد الصفحات؟ مجموع أحرف المتن الأصلي = المولّد؟
- كل حاشية أصلية موجودة في sources؟ وكل sup له li؟
- المشجرة ≥ ٣ مستويات ولا عقدة فيها منسوخة حرفياً من المتن؟
- كل روابط toc لها ملف وكل anchor له id؟ كل JSON سليم؟ prev/next صحيحة؟ description فريد لكل صفحة؟

## صيغة التسليم
كل ملف كاملاً في كتلة كود يسبقها مساره، بهذا الترتيب: index.html للكتاب، ثم الصفحات 001…N، ثم search-index.json، ثم data/manifest.json كاملاً، ثم sitemap.xml كاملاً، ثم جدول التحقق.

## إذا وصل الكتاب على أجزاء
أنجز كل جزء فوراً مع تحديث تراكمي لـ manifest وsitemap، وحافظ على تسلسل الترقيم والمعرفات (p-… و s-… و fn-…) بين الأجزاء، وعند الجزء الأخير أرسل جدول التحقق الكامل.
